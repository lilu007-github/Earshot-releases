# Earshot for Mac — 下载 / Downloads

在 [Releases](https://github.com/lilu007-github/Earshot-releases/releases/latest) 里下载最新的安装包：

- **Earshot-<版本>.dmg**：完整版，实时转写、翻译、会议记录、说给会议听。

Download the latest installers from [Releases](https://github.com/lilu007-github/Earshot-releases/releases/latest):

- **Earshot-<version>.dmg**: the full app: live transcription, translation, meeting notes, Speak to Meeting.
- **Hibiki-<version>.dmg**: the simple app for subtitling videos.

Requires macOS 26 (Tahoe) on Apple silicon. Open the DMG and drag the app to Applications; the first time, allow it once in System Settings as described in "How to Install.txt" inside the DMG. Earshot then tells you about new versions.

This repository holds installers only; the source code is not here.
